## Netflix NextJS Clone
------------------------------------------------------------------------------------------------------------------------------------------------------

### Deployment

-  <a href="https://netflix-next-js24-cy62i02e7-woorikis-projects.vercel.app/browse">Netflix Page - clone project</a>

이 프로젝트는 Netflix와 유사한 스트리밍 서비스 웹 애플리케이션입니다.<br/>
사용자는 영화와 TV 프로그램을 탐색하고, 즐겨찾기에 추가하고, 로그인 및 회원가입 기능을 통해 개인화된 유저 경험을 할 수 있습니다.

### Main Features

- **사용자 인증:**
  - GitHub를 통한 소셜 로그인 기능을 구현하였습니다. (next-auth)
- **TMDB:**
  - 영화 데이터를 기반으로 필터링하여 해당 컨텐츠 조회하며, 컨텐츠에 포함된 items을 화면에 렌더링 합니다.
- **컨텐츠 관리:**
  - 미디어 아이템 즐겨찾기 추가 및 제거
  - 목록 보기 및 세부 보기 전환
  - 검색 기능을 제공합니다.

### Tech Stack

- **프레임워크 및 라이브러리:**

  - **Next.js:** React 기반의 서버 사이드 렌더링(SSR) 및 정적 사이트 생성(SSG)을 위한 프레임워크입니다.
  - **React:** 효율적인 UI구성과 빠른 렌더링을 지원하는 컴포넌트 기반 JavaScript 라이브러리입니다.
  - **Tailwind CSS:** 별도의 CSS를 작성하지 않고 HTML이나 JSX에 미리 정의된 클래스를 직접 적용하여 디자인을 빠르게 프로토타입하고 일관된 스타일링을 유지할 수 있습니다.
  - **Framer Motion:** 자연스러운 애니메이션과 트랜지션을 간편하게 구현할 수 있는 라이브러리며, 직관적으로 적용하고 조정할 수 있습니다.

- **인증:**

  - **NextAuth.js:** 사용자의 로그인 및 세션 관리를 간편하게 처리하며, 보안성과 확장성이 뛰어난 인증 솔루션을 제공합니다.

- **아이콘:**

  - **Heroicons:** Tailwind CSS에 맞춰 설계된 무료 SVG 아이콘입니다.

- **이미지 관리:**
  - **Next.js Image 컴포넌트:** 최적화된 이미지 로딩 및 크기 조정을 위한 컴포넌트입니다.
